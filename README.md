# Nexapulse E-commerce Website

A responsive React + Tailwind CSS storefront concept for Nexapulse, a Bangladesh-based consumer tech shop.

## Features
- Responsive dark-premium storefront
- Product categories and search
- Sort by featured, price, and name
- Add-to-cart, quantity controls, remove items
- Wishlist toggles
- Demo checkout form and confirmation state
- Contact links for phone, email, and WhatsApp
- Placeholder product illustrations drawn with CSS

## Start locally
1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite.

To make a production build:
```bash
npm run build
```

## Important before launch
This is a frontend demo, not a live store. Product names, prices, discounts, and artwork are placeholders. Replace them with real products and verified prices. Checkout does not submit an order to a server and no payment gateway is connected. Do not accept real payments until you add a secure backend, inventory/order management, privacy and return policies, and properly configured payment integrations. Contact information is configured from the details provided by the business owner.
